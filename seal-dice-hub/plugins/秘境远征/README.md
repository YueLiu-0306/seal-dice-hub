# 秘境远征 v3.0

多人合作 Roguelike 地牢冒险游戏插件，基于海豹骰框架开发。

## 文件说明

| 文件 | 说明 |
|------|------|
| `秘境远征v3.0.js` | 插件主文件，上传到骰娘 plugins 目录 |
| `backend/expedition_image_backend.py` | 图片后端，Flask 服务，端口 8015 |

## 部署步骤

### 1. 部署 JS 插件

将 `秘境远征v3.0.js` 上传到海豹骰的 `plugins` 目录，在 UI 中重载脚本。

### 2. 部署图片后端（可选）

```bash
pip install flask pillow
python backend/expedition_image_backend.py
```

启动后访问 `http://127.0.0.1:8015/api/test` 验证是否正常运行。

### 3. 骰娘 UI 配置

- `IMAGE_ENABLED`: `true`（开启图片输出）
- `IMAGE_BACKEND`: `http://127.0.0.1:8015`（后端地址）

## 职业一览

| 职业 | 特性 | 定位 |
|------|------|------|
| 战士 | 战意狂潮：HP每降10点+15%攻击，BOSS战血盾分半 | 持续输出 |
| 法师 | 奥术亲和：技能伤害+60%，技能书额外加成 | 爆发输出 |
| 祭司 | 复苏之风：全体恢复已损失HP 10% | 辅助治疗 |
| 刺客 | 夺命追击：暴击2.5x，BOSS越弱暴击越高 | 爆发输出 |
| 守卫 | 不动如山：常驻减伤20%，嘲讽代承+反伤 | 前排坦克 |
| 狂战士 | 战斗意志：每回合+2ATK-2HP，越战越强 | 持续输出 |
| 愚者 | 混沌共鸣：每回合随机获得一个职业被动 | 随机应变 |
