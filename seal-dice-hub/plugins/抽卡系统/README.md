# 抽卡系统

每日抽卡 + 十连抽卡系统，内置水晶商店，支持图片输出。
该系统最初基于他人所上传的同名插件所修改，其基本框架沿用该大佬，但后续开发追加并无参考。

## 文件说明

| 文件 | 说明 |
|------|------|
| `抽卡_图片版.js` | 图片版抽卡插件（含十连图片生成） |
| `每日抽卡for商店系统_通用版.js` | 通用版抽卡插件（内置水晶商店，文字输出） |
| `backend/gacha_image_backend.py` | 图片后端，Flask 服务，端口 8014 |

## 部署步骤

### 1. 部署 JS 插件

选择需要的版本上传到骰娘 `plugins` 目录：
- **图片版**：支持十连抽卡结果以图片形式输出
- **通用版**：内置水晶商店系统，文字输出

### 2. 部署图片后端（仅图片版需要）

```bash
pip install flask pillow
python backend/gacha_image_backend.py
```

### 3. 骰娘 UI 配置

在插件配置面板中设置后端地址（默认 `http://127.0.0.1:8014`）。
